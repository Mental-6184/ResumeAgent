PocketLedger — 微信小程序记账应用

项目名称：PocketLedger
技术栈：微信小程序原生框架 + JavaScript + WXML + WXSS + 微信本地存储 API
仓库：github.com/Mental-6184/PocketLedger

项目描述：面向日常生活的个人记账微信小程序，主打轻量、本地优先、可快速记账。数据通过本地存储持久化，不依赖后端即可运行。

核心功能：
- 自定义数字键盘，提升记账录入效率
- 收入/支出双类型记账，常用分类快捷记账
- 按备注、分类名、账户名关键词搜索记录
- 月度预算设置与预算使用进度展示（绿色70%以内→黄色70%-90%→红色90%以上）
- 订阅项目管理与到期提醒（周付/月付/季付/年付）
- 订阅到期自动检测，弹窗确认后自动生成扣费记录
- 订阅扣费日历视图
- 多币种订阅金额录入与人民币换算（CNY/USD/EUR/GBP/JPY/HKD/KRW）
- 年付订阅按月分摊能力
- 账户资产管理（预置微信钱包/支付宝/储蓄卡/现金），追踪钱在哪里
- 支付方式关联，记账时选择付款账户，自动同步账户余额
- 待报销标记与退款冲抵，不污染收支统计
- 月度统计、分类占比、账户收支、退款报销、近 6 个月趋势分析
- 数据导出为 CSV 表格或 JSON 备份，通过微信分享保存
- 数据导入带格式校验，防止错误数据破坏本地存储

性能优化（v2.0.0）：
- 数据层内存缓存机制，避免每次读取都访问 wx.getStorageSync
- 首页多次数据遍历合并为单次遍历
- 统计页面分批渲染，核心数据优先渲染
