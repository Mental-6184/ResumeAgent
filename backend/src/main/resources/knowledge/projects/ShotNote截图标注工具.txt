ShotNote — Electron Windows 截图标注工具

项目名称：ShotNote
技术栈：Electron + screenshot-desktop + tesseract.js + electron-builder + 原生 HTML/CSS/JS
仓库：github.com/Mental-6184/ShotNote

项目描述：基于 Electron 构建的 Windows 截图标注工具，面向日常沟通、问题反馈、产品说明、测试提单、教程整理等场景，提供从截图、选区、标注、OCR 到导出的一体化桌面工作流。

核心功能：
- 全局快捷键截图（Ctrl + Alt + Shift + S）
- 多屏幕区域截图（支持双屏、三屏办公场景）
- 截图后直接进入编辑器，无需额外保存或切换工具
- 丰富标注工具：画笔、高亮、矩形、箭头、文字、马赛克、模糊、拖拽
- 画布缩放与视图控制（放大/缩小/适应窗口/空格平移/Ctrl+滚轮缩放）
- OCR 文字识别（tesseract.js，支持中文+英文、中文、英文三种语言预设）
- 导出与剪贴板复制（复制到剪贴板 / 导出 PNG）
- 历史记录管理（自动保存导出记录，支持回看和重新打开）
- 本地图片二次标注（拖入编辑器继续标注）
- 托盘常驻（系统托盘后台运行）

项目结构：主进程（main.js）负责窗口管理、托盘、快捷键、IPC 通信；渲染进程（src/）负责编辑器交互、画布绘制、OCR 调用、历史记录
