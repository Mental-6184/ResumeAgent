智能车库/园区车辆管理系统 — 已获国家软件著作权

项目名称：智能车库管理系统（智能园区车辆管理系统）
技术栈：Spring Boot + MyBatis-Plus + MySQL + Docker + Vue（部分版本）
开发时间：2025.03-2025.04
角色：独立开发

项目描述：基于 Spring Boot + MyBatis-Plus + MySQL 开发一体化车库管理平台，设计多策略计费规则引擎、订单流水统计与数据可视化模块，支持多端交互。已取得国家计算机软件著作权。

核心功能：
- 车辆登记与管理
- 停车计费（多策略计费规则引擎）
- 入出库数据管理
- 订单流水统计
- 数据可视化模块
- 多端数据交互

技术亮点：
- 多策略计费规则引擎设计，提升系统业务扩展能力
- 独立负责数据库建模与物理表设计
- 高内聚低耦合的业务接口开发与联调
- 事务控制保障入出库数据强一致性
- Docker 容器化部署
- 全链路 Bug 修复
